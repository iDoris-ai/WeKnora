# TODO-B：默认一站式知识库配置

2026-10-11｜状态：产品 TODO / BACKLOG；[追踪 Issue #1](https://github.com/iDoris-ai/WeKnora/issues/1)。本文件记录用户明确提出的产品要求；不启动代码、修改当前安装、购买模型或改变 Agent24 既有任务优先级。

主对话归属遵循 [ADR-001](ADR-001-SINGLE-CONVERSATION.md)：知识页负责资料/Wiki 管理，提问与追问统一进入 Agent24。

关联：iDoris-ai/Agent24#904（跨仓接入约定）、iDoris-ai/Agent24#713（Line K）、fork `docs/agent24/WEKNORA-INTEGRATION-PROPOSAL.md`。

## 为什么必须改

用户实测新建知识库界面，需要依次理解基本信息、模型配置、向量存储、解析引擎、分块设置、图像处理、音频处理、知识图谱、高级设置和存储引擎。这是一组管理员/研发配置，而不是个人用户或普通组织职员的使用流程。

让普通用户选供应商、Embedding、向量数据库、4K/16K 分块等，既增加首次使用成本，也不能得到可信的技术决策。知识库应该是购买/激活后可直接使用的产品能力，而不是交给用户组装的技术平台。截图只用于分析菜单，没有上传截图或任何用户资料。

## 首版产品目标

**激活产品 → 回答最多 2–3 个自然语言问题 → 自动初始化 → 上传资料/直接提问。**

- 复用 Agent24 身份、现有授权和销售方案，不要求用户另外注册 WeKnora、创建空间、配置模型，再建库。个人初次安装可采用受控本机身份初始化；企业身份必须由已验证组织成员关系决定。
- 默认问题：个人/组织使用（若购买档位已确定则不问）、组织/工作空间显示名称、资料处理方式确认。可用职业/用途替代已知问题；保留可跳过的非必需项，不强制填写业务背景。
- 支持文字和语音答复，提交前展示识别结果可纠正；语音入口优先复用 Agent24/AgentEar 的已授权能力，不要求另配 ASR。文本流程不被语音集成阻塞，麦克风和语音外传单独遵守授权。
- 名称只是显示信息，不构成组织身份或 ACL；说出某公司名称不能加入该公司或读取其资料。
- 成功后的主页面只有资料/上传、问答、处理中任务和必要的账户/方案状态。上述技术菜单不出现在普通用户主流程，只留给获授权管理员/支持人员的独立诊断入口。
- “创建组织/空间/知识库”是后台实现步骤，不是用户必须逐项操作的产品步骤；重复启动、安装中断、重复激活不能重复建库。

## 一套可交付的内置方案

由我们维护版本化配置档，内置聊天/Embedding 配对、向量与原件存储、解析/分块策略、资源预算、已支持的图片/音频处理和可选能力开关。个人 Lite/组织服务共用产品流程，后端参数按部署档映射。

初期采用经过代表语料验收的保守默认值，不把算法选择或调优指标交给普通用户。没有必要默认开启知识图谱、图片大模型、音频和昂贵处理；购买档位、资料类型、设备资源及用户允许的处理方式共同决定能力。未支持格式在上传前说明，不允许“上传成功但其实不能用”。

初始化需核验身份、服务能力、聊天/Embedding 可用性、存储写入和限额，必要时运行无用户内容的连接测试。未完成时显示“正在准备/需激活/服务暂不可用/方案不含该能力”，并提供可操作帮助；不让用户猜哪个模型参数错了，不用 health 200 冒充全部 ready。

## API、License 与密码的交付边界

用户希望购买我们的 API/配置方案，下载后直接使用。推荐交付**激活码/签名授权配置＋受限服务身份**，而不是在所有安装包里塞同一把供应商 API Key。

- 配置包含非敏感端点、方案、版本、能力、配额/到期信息；私密凭据通过受控激活/加密配置导入，按用户/组织签发，可轮换和撤销。
- 模型访问优先经过我们的受控网关，供应商根 Key 留在服务端。确需交付客户自有 Key 或连接密码时，以专用账户和最小权限处理；客户端用系统凭据存储，服务器用对应 secret 存储，不放仓库、截图、日志、URL 或通用明文配置。
- License 的销售授权、组织成员身份、工具执行许可和资料外传许可是不同维度；激活成功不能自动获得管理员权限、共享私有资料或外发批准。
- 用普通语言告知资料在哪里处理、价格/配额和超额行为；默认不自动续费、购买更贵模型、突破费用上限或在本地失败后偷偷切云端。销售前核对供应商转售/代调用条款与模型/依赖许可证。方案价格、License 格式和销售网关尚需单独设计，不能声称已交付。

## 使用后的学习与调优

### 首版：渐进询问，而非配置问卷

用户先使用；系统根据明确授权的资料/任务发现缺少背景时，只问有助于当前任务的问题，支持跳过、纠正和暂停。个人偏好仍归 Agent24 记忆；组织事实、背景卡和 SOP 更新先形成候选，用户/有权负责人确认后发布到 KB。不得默认读取全盘、全部聊天或组织资料，也不能把模型推断写成已确认事实。

### 后续 TODO：受控自适应调优

可由有界 Agent 分析处理失败、引用质量、用户纠错、延迟和成本，提出参数/处理策略调整。先离线评测，再按预算小范围验证，保留版本与回退；不能宣称 Agent 看见几个评分就一定会自动优化。

Embedding 更换/向量维度变化、大规模重索引、提高费用、改变处理目的地、共享范围或原件生命周期必须按相应权限/审批门执行。不得为“调优”自动删除原件、扩大资料权限、重写已审规范或自购服务。这部分不是首版初始化的前置。

## 跨仓实现分工

- **WeKnora fork**：内置配置档和能力预检、幂等默认库初始化、Vue 一站式页/普通用户视图、嵌入模式、后端权限强制执行；隐藏菜单不能代替后端授权。
- **Agent24**：既有身份、激活/凭据桥、文字/语音引导、受限宿主调用和状态、默认上下文/个人记忆与写入审批；不复制整套 WeKnora UI。
- **销售/服务端**：License/订阅、每客户凭据与计费/配额、受控模型入口和运维。具体负责人和实现仓库待确认，不默认为 Line K owner 的全部新增工作。
- 接口、数据流和页面隔离继续遵守 Agent24#904；既有 Line K owner 不因此改派，暂停路线不因此恢复。

## 可观察验收标准

- [ ] 已激活、服务就绪的全新个人安装，以及授权组织成员首次使用，均能在不填写技术参数、不额外注册 KB 账号的情况下完成初始化。
- [ ] 最多 3 个必需问题；文字/语音均可纠正；已知信息不重复询问。
- [ ] 普通主流程不出现模型供应商、Embedding、向量库、分块、解析器或存储引擎必填项。
- [ ] 固定方案下上传代表文档 → 等待完成 → 提问 → 打开正确引用的端到端测试通过；此时才称知识库可用。
- [ ] 初始化中断、重启、重复激活/登录不重复创建库；用户已有资料/配置和人工修订不被覆盖。
- [ ] 激活过期、额度不足、网络/模型不可用、资源不足均有普通语言提示与恢复路径，不假成功、不暗中加费。
- [ ] 无共享根 Key/密码泄漏；本地/企业切换与两用户两组织权限负例通过。管理员能力不因输入组织名或 License 激活而开放。
- [ ] 未经授权无敏感资料、语音或正文遥测外发；组织事实/SOP 与个人偏好更新分别可审阅、纠正、撤回。
- [ ] 后续调优保持独立任务；首版不依赖其完成，不覆盖原件、权限与人工知识。

完成定义：普通用户能直接使用知识能力，不必理解 RAG 平台的运维术语。仅把菜单折叠、预填几个模型字段，或者做一个仍需后台人工补配置的向导，均不算完成。
